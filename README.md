# Deltachrome

Target analysis for libraries, archives, and museums. Deltachrome measures
captures of imaging test targets against FADGI and Metamorfoze guidelines,
or against guidelines of your own.

Website and user guide: https://permachro.me/deltachrome/

Deltachrome is in beta. Downloads will appear under Releases, and the source
code will be published here.
