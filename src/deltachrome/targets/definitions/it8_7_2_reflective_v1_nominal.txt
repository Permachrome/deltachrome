KEYWORD	"DELTACHROME_NOMINAL_CAVEAT"
DELTACHROME_NOMINAL_CAVEAT	"The values are batch averages, not design aims and not a measurement of the chart in front of you. Their own arithmetic says so: they quantize to 0.002 rather than to 0.01, which is what a mean of five readings each taken to two decimals does, and ISA print the same convention outright on the Golden Thread Object Level Target -- 'All values are batch averages'. A batch mean sits closer to any individual unit than a design aim would, which makes it better data; it also looks exactly like a per-unit measurement and is not, which is why a run against it reports ADVISORY and makes no conformance claim for the specimen. IT8 reference data is per BATCH by design, and the batch is printed on the chart, beside a barcode carrying the same string. Every IT8 vendor publishes the data for every batch they sell. Using this file against a chart from another batch is the exact error the per-unit rule exists to prevent, and it is avoidable here in a way it is not for most targets: read the chart's own batch number and fetch that batch's file. For the 264-patch colour array specifically, that advice is stronger than usual -- these are not a batch file at all, but one physical chart's own FD7 measurement, so they already carry the specimen's own accident with no batch mean to average it away. Columns 20-22 (A20-L22) are not in this file. The IT8.7 standard leaves them to each manufacturer, so values for them describe one vendor's chart and no other; they are judged only against a reference file for the chart in front of the camera, which carries them."
