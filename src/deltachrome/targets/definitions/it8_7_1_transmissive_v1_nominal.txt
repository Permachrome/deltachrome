The 264 patch ids A1-L22 match the chart's own printed row letters and column numbers, and the twelve density-bearing steps are column 16 in row order A to L, which is the neutral column of the IT8 layout. GS0-GS23, the 24-step grayscale strip below the array, were added directly from LaserSoft's own currently published batch-average file for E180106 (silverfast.com/it8calibration, fetched 2026), rather than through OpenDICE, whose profile carries no values for the strip at all. That file's own A1-L22 values agree with OpenDICE's to 0.000 dE(ab) across all 264 patches, exactly -- the strongest cross-check this project has for any reference file -- so the GS values it also carries are trusted on the same batch identity."
KEYWORD	"DELTACHROME_NOMINAL_CAVEAT"
DELTACHROME_NOMINAL_CAVEAT	"The values are batch averages, not design aims and not a measurement of the chart in front of you. Their own arithmetic says so: they quantize to 0.002 rather than to 0.01, which is what a mean of five readings each taken to two decimals does, and ISA print the same convention outright on the Golden Thread Object Level Target -- 'All values are batch averages'. A batch mean sits closer to any individual unit than a design aim would, which makes it better data; it also looks exactly like a per-unit measurement and is not, which is why a run against it reports ADVISORY and makes no conformance claim for the specimen. IT8 reference data is per BATCH by design, and the batch is printed on the chart -- E180106 on the specimen these values came from, beside a barcode carrying the same string. Every IT8 vendor publishes the data for every batch they sell. Using this file against a chart from another batch is the exact error the per-unit rule exists to prevent, and it is avoidable here in a way it is not for most targets: read the chart's own batch number and fetch that batch's file. These values describe a photographic emulsion on a film base. Lightness is what the reference states; density is stated only for the neutral column. Columns 20-22 (A20-L22) are not in this file. The IT8.7 standard leaves them to each manufacturer, so values for them describe one vendor's chart and no other; they are judged only against a reference file for the chart in front of the camera, which carries them."
